# 학습 요약
###  run, upload, monitor
- 컴파일과 실행은 다르다
- pio run: 코드를 컴파일해서 바이너리 파일 생성
  - 프로그램을 빌드하는 과정
- pio run -t upload: 바이너리를 ESP32에 전송
  - 컴퓨터에서 만든 프로그램을 ESP32의 플래시 메모리로 전송하는 과정
- pio device monitor -p COM7 -b 115200
  - esp32 출력 확인

### PlatformIO, CP2102 드라이버
- PlatformIO: 빌드와 업로드 관리
- CP2102 드라이버: USB와 UART 변환
- 운영체제: COM7 포트 제공
각 계층이 연결되어야 코드가 실제 하드웨어에서 실행된다.

### USB, UART, COM*
- USB는 컴퓨터와 보드가 연결되는 물리적 통신 방식
- UART는 데이터를 주고받는 직렬 통신 방식
- COM7은 운영체제가 UART 장치에 붙인 이름입니다.


### 입력과 출력, GPIO
- GPIO는 하드웨어의 입출력 인터페이스
- OUTPUT: ESP32가 전기 신호를 보냄
- INPUT: ESP32가 버튼이나 센서 신호를 읽음


**시리얼 모니터와 업로드 프로그램은 COM 포트를 동시에 사용할 수 없다.**
**하나의 자원을 여러 프로그램이 사용하려 하면 PermissionError가 발생**
