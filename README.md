# embedded

학습한 날마다 폴더를 하나씩 만들고, 그 안에 코드와 그날의 정리(README)를 남깁니다.

## 폴더 구조 규칙

새로 학습한 날에는 아래 규칙으로 기록을 추가합니다.

1. `DAY{N}_{주제}` 형식으로 폴더 생성 (예: `DAY3_ultrasonic`)
2. 해당 폴더 안에 `README.md`로 그날의 학습 정리 작성
   - 오늘 무엇을 만들었는지 / 목표·결과
   - 배선·구성도 (해당하는 경우)
   - 배운 개념 정리
   - 디버깅 중 겪은 문제와 해결 방법
   - 다음에 해볼 것 (TODO)
3. 이 루트 `README.md`의 [학습 기록](#학습-기록) 표에 한 줄 추가
   - Day / 날짜 / 주제 / 핵심 키워드 / 폴더 링크

```
DAY{N}_{주제}/
├── README.md      # 그날의 학습 정리
├── src/main.cpp    # 코드
└── platformio.ini
```
